# m1 역량 뽑기

공고 한 건을 문장으로 나누고, 공고가 원하는 역량을 뽑는다. 역량마다 유형(수행·지식·도구·협업·태도), 필수·우대, 근거 문장 번호를 단다.
m2 와 m3 가 이 목록을 받는다.

```bash
.venv/bin/python -m m1_competency.extract 공고.txt         # 공고 글 파일 → 역량 JSON (모델을 한 번 부른다)
```

- 문장 나누기와 필수·우대 가르기는 규칙으로 한다 (`competencies.py`, `collect.lines`). 모델은 역량 이름과 유형만 낸다.
- 근거 문장 번호가 공고에 없는 역량은 버린다. 필수·우대는 모델이 아니라 근거 문장이 있는 구역(자격요건·우대사항)이 정한다.
- 예시 두 건의 결과는 `data/results/<예시>.json` 에 있다. 데모와 m2·m3 는 이 파일을 읽는다.
- 회사 채용 사이트에서 공고를 모으려면 `python -m m1_competency.collect fetch <회사>` (회사 목록은 `data/companies.json`). robots.txt 를 따르고 한 호스트에 초당 한 번만 묻는다. 모은 공고는 회사의 저작물이라 이 레포에는 넣지 않았다.
- 추출을 사람 정답과 견준 실험은 `experiment/` 에 있다.
