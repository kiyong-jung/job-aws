## 반드시 (화면끼리 숫자가 어긋남)

1. 3단계 답 한 줄이 ④ 쪽 범례와 다른 수를 말한다 (원칙 4, U14). 한 줄은 "자료로 공부한다"고 하는데 ④ 범례는 "맞는 자료가 없는 것"을 따로 센다.
   - 하루 1시간: `84시간 중 · 큰 항목 17개를 자료로 공부해요 · 33시간은 남아요` (④: 자료로 공부할 것 13개, 맞는 자료가 없는 것 4개)
     → `84시간 중 · 13개를 자료로 공부해요 · 33시간은 남아요`
   - 하루 2시간: `168시간 중 · 28개 모두 자료로, 더 볼 자료까지 · 48시간은 남아요` (④: 26개, 없는 것 2개. "모두"가 틀림)
     → `168시간 중 · 26개를 자료로, 더 볼 자료까지 · 48시간은 남아요`
   - 하루 3시간: `252시간 중 · 따라 해 볼 자료까지 더해요 · 90시간은 남아요` (몇 개인지, 무엇에 더하는지 없음)
     → `252시간 중 · 27개를 자료로, 따라 해 볼 자료까지 · 90시간은 남아요`
   - 세 줄이 "N개를 자료로 + 더 얻는 것 + 남는 시간" 같은 틀이 된다. N은 `found` (④ "자료로 공부할 것"과 같은 값). spec 9절 5의 문구가 틀린 것이라 spec 도 같이 고친다.
   - "큰 항목"은 여기에만 나오는 셋째 이름이다 (진행 글·④ 쪽은 "따로 공부할 것"). 위 고침으로 없어진다 (원칙 7).

## 고침

2. 질문과 단추에 "교육자료"가 없다 (원칙 1). 전에는 단추가 `교육자료 찾기`였는데, 지금 `하루 1시간으로 찾기`만 보면 무엇을 찾는지 모른다. 회색 곁글 "고른 시간에 맞춰 교육자료를 찾아요. 나중에 바꿀 수 있어요"를 지우며 같이 빠졌다.
   - `팀원 한 명이 하루에 얼마나 공부할 수 있나요?` → `교육자료를 찾을게요. 팀원 한 명이 하루에 얼마나 공부할 수 있나요?`
   - 단추 `하루 1시간으로 찾기` 는 그대로 (질문이 목적어를 준다. 390 에서 세로로 쌓여도 한 줄).
3. 4단계 한 줄의 "한 주 21시간"이 고른 "하루 2시간"과 이어지지 않는다 (원칙 5, U14). 하루 2시간이면 한 주 14시간인데 21이 나온다. 풀이(공부 14 + 프로젝트 7)는 회색 어림 줄과 함께 지워져 화면 어디에도 없다. 하루 3시간도 같다 (21 + 7 = 28).
   - `한 주 21시간까지 · 12주 중 10주는 그 안에 해요` → `한 주 21시간까지 (공부 14 + 프로젝트 7) · 12주 중 10주는 그 안에 해요`
   - 1440 대화 칸에서 한 줄에 들어간다. ⑤ 점선 이름표 `한 주 21시간까지` 는 그대로 둔다.
4. 같은 남는 시간을 3단계와 4단계가 다른 말로 두 번 한다 (원칙 3, S9).
   - 3단계 한 줄: `· 48시간은 남아요` / 4단계 짧은 줄: `공부 168시간 중 48시간은 아직 비어 있어요. 복습에 쓸 수 있어요.`
   - → 4단계 줄을 `남은 공부 48시간은 복습에 쓸 수 있어요.` 로 ("남아요" 한 말로, 견주는 수는 3단계가 이미 말함).
   - 하루 1시간: `공부 84시간 중 33시간은 아직 비어 있어요. 하면서 배울 것 11개와 복습에 쓸 수 있어요.` → `남은 공부 33시간은 하면서 배울 것 11개나 복습에 쓸 수 있어요.` ("11개와 복습에"는 "11개와 함께"로도 읽힌다)
5. 하루 2·3시간의 첫 진행 줄은 하는 일이 없다 (원칙 3, spec 3절 "실제로 일어나는 단계만").
   - `공부할 거리 28개를 모두 따로 공부할 것으로 놓는 중` → `공부할 거리 28개를 모두 놓았어요`
   - 나누지 않으니 이 줄을 뺀다. 남길 거면 하는 중·했어요가 같은 말이어야 한다 (S12): `… 따로 공부할 것으로 놓는 중` ↔ `… 따로 공부할 것으로 놓았어요` (지금은 끝난 말에서 "따로 공부할 것으로"가 빠짐).

## 손볼 것

6. 하루 1시간 자료 고르기 줄만 역할 이름이 없다 (원칙 7, 한 이름). 2·3시간은 `먼저 볼 자료를 고르는 중`.
   - `자료 9,723개에서 따로 공부할 것 17개에 맞는 자료를 고르는 중` → `자료 9,723개에서 따로 공부할 것 17개에 먼저 볼 자료를 고르는 중` (끝난 말도 같이)
7. 자료 없는 것 줄은 "자료"를 두 번 쓰고, 할 일이 막연하다 (원칙 2·8, S14).
   - `맞는 자료가 없는 것 4개는 자료를 따로 찾아 채울 수 있어요: 채점기 검증하기, …` → `맞는 자료가 없는 것 4개예요: 채점기 검증하기, …`
   - 시간을 늘리면 채워지는 수가 저장본에 있으면(1시간 4개 → 2시간 2개) 끝에 `하루 2시간이면 2개로 줄어요` 를 붙이면 막힌 곳에서 할 일 하나가 된다. 숫자는 저장본에서 센다.
8. "끝까지 못 다루는 역량은 Unreal Engine 1개예요"가 2·4·5단계 답에 세 번 나온다 (S9 상한). 공부 시간과 상관없는 4단계 줄은 뺀다.
   - 4단계 `끝까지 못 다루는 역량은 Unreal Engine 1개예요. 까닭은 응용 프로젝트 쪽에 있어요.` → (지움)
9. 넘침을 세 말로 부른다: 표 머리 `넘침`, 범례 `넘친 시간`, 짧은 줄 `넘는 주:`. 하나로 맞추면 좋다 → 짧은 줄 `넘친 주: 4주차 +27분 · 5주차 +4시간 42분. 옆 주로 옮겨 맞출 수 있어요.` (`weeks.js` 좁은 화면 줄이 이미 "넘친 주"를 씀).

## 잘 된 것 (그대로 둔다)
- "하루 N시간" 한 이름: 단추·라디오 칸·내 말(`하루 2시간으로 교육자료를 찾아 줘`)·복사 머리(`교육자료는 하루 N시간 기준`)가 같다. 안·예산 같은 말은 화면에 없다.
- 바꿔도 내 말풍선 글이 따라 바뀌고 대화에 새 말이 붙지 않는다 (33 사진). 실패 알림 `공부 시간을 바꾸지 못했어요. 지금 그림은 그대로예요` 는 원칙 8에 맞다.
- 회색 곁글을 지운 뒤에도 ④ 눈금(84·168·252)과 막대가 목표선 이름표 없이 읽힌다.

판정: 1번(한 줄의 개수가 ④ 범례와 어긋남)과 2·3번만 고치면 내보낼 수 있고, 나머지는 문장 손질이다.
