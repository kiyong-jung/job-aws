## 찾은 것

**1. [med] 깔때기: › 가 숫자가 아니라 이름표 끝에 붙어, 1440 에서 숫자와 › 사이가 약 8 / 24 / 70px 로 다르다 (U5, 1차 3번이 남음).**
- 증거: 12-scene-c-pick-1440, 15-back-to-search-1440. "111,753개 ›" 는 붙어 있고 "100개 ›" 는 멀다. 17-panel-head-360 은 거꾸로 "111,753개›" 가 붙는다(600 아래 `column-gap: 0`).
- 원인: panel.css:129 `grid-template-columns: auto 16px auto …` 의 auto 칸 너비를 이름표("역량마다 다시 고른 후보 ✓")가 정한다. 숫자는 그 칸 왼쪽에 붙으니 › 와의 거리가 이름표 길이만큼 늘어난다. shots.py 는 "› 칸 너비 같음"을 보니 통과한다. 눈에 보이는 것은 숫자 끝 ↔ › 거리다.
- 고칠 것: `.stop { align-items: flex-end; text-align: end }` 로 네 칸을 오른쪽 맞춤한다. 그러면 이름표 끝과 숫자 끝이 같은 세로선에 서고, › 는 늘 8px 뒤에 온다. 600 아래에서는 `column-gap: 2px` 을 남긴다. shots.py 의 검사는 "숫자 오른쪽 끝 → › 왼쪽 끝 거리 셋이 ±2px" 로 바꾼다.
