# 작은 회색 글씨 정리 기록 (U4-1, 2026-11-18)

기준: `DESIGN_RULES.md` U4-1, `v5-budget-spec.md` 7절, 목록은 `design/proposals/budget-frontend-design.md` 11절. 줄마다 지움 / 올림 / 접음 중 하나.
- 지움: 화면에서 없앴다 (뜻은 `aria-label`·README·저장본에 있다).
- 올림: 13px 이상 먹색(`--ink`)으로 올렸다. 12px 크기 토큰(`--fs-meta`)은 쓰는 곳이 0이라 `tokens.css` 에서 지웠다.
- 접음: 접힌 곳 안으로 넣었다.

예외 (spec 7절): 단계 길의 아직 안 그린 쪽 이름(`--faint`), 입력창 안내 글(placeholder). `--muted` 는 짝 보기에서 다른 줄을 흐리게 하는 `[data-focus]` 상태에만 남았다 (글 줄이 아니라 강조 상태).
`shots.py` 의 `SMALL_TEXT` 가 사진마다 "13px 아래 글, `--muted` 색 글"이 0개인지 센다.

|---|---|
