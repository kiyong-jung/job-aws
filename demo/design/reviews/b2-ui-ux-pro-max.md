## 손볼 것
A. **고른 칸이 바탕 차이로는 거의 안 보인다.** 흰 칸과 칸 바탕(#f0eee6)의 대비는 약 1.15:1이고, 테두리는 `--line`(먹 12%)이다. 사실상 굵기(500 → 600)만으로 구분된다. 빔 프로젝터에서는 흐려질 수 있다 (가이드 `state-clarity`, WCAG 1.4.11 은 3:1).
   - 고침: 고른 칸에만 `box-shadow: 0 0 0 1px var(--line-strong), 0 1px 2px rgba(43,42,39,.08)`. 테두리는 고른 칸 하나에만 둬서 리드 4번("테두리 셋 없음")과 부딪히지 않는다. 390 의 `대화 | 과정` 칸에도 똑같이 적용해 두 칸 모양을 맞춘다.
B. **④ 의 "맞는 자료가 없는 것" 조각이 손잡이처럼 보인다.** 252 에서는 1개, 3시간이라 1440 에서 약 8px, 390 에서 약 4px 너비의 흰 네모가 된다. 이것이 칠한 막대 끝에 붙어 있어, 끌어서 바꿀 수 있는 슬라이더 손잡이로 읽힌다 (`30-budget-252-materials-1440.png`, 390 은 직접 띄워 확인). 막대는 누를 수 없는 그림이다.
   - 고침: 빈 조각은 흰 칠 없이 위아래 1.5px 선만 남긴다 (`.seg[data-state=none] { background: transparent }`). 범례의 □ 와 같은 뜻은 그대로 유지된다.
C. **"하면서 배울 것 11개"의 범례 네모가 가리키는 것이 막대에 없다.** 84 의 세 번째 묶음에 `--line-strong` 1px 네모(대비 약 1.6:1)가 붙어 있지만, 막대에는 이 묶음이 그려지지 않는다 (`33-budget-roundtrip-1024.png`). 범례 칸은 그림 속 표시와 짝이 있어야 한다.
   - 고침: 이 줄의 네모를 빼고, 같은 너비의 빈 자리(10px)만 둬 글 시작 위치를 맞춘다.
