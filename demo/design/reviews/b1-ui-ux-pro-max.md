# 공부 시간 고르기 검토: ui-ux-pro-max 눈으로 (b1, 2026-11-18)

기준: `design/guides/ui-ux-pro-max.md` (접근성 → 누르기 → 모양 → 글자·색 → 움직임 순), `DESIGN_RULES.md` 1절(U4-1 포함), `v5-budget-spec.md` 1~9절.
본 것: `shots/` 의 19·30·31·32·33·34 사진 (1440·1024·390), `budget.js`·`study.js`·`panel.css`·`tokens.css`.
직접 확인: 8793 포트에 서버를 띄우고 머리 없는 Chrome 으로 1440 에서 Tab·화살표·알림·aria 를 읽었다 (끝나고 서버는 껐다).

## 잘된 것 (확인함)
- 고르기 칸은 진짜 `fieldset` + 라디오, 화면 읽기 이름 "하루 공부 시간". 세 칸 모두 높이 44px (1440 에서 너비 199px, 390 에서도 한 줄).
- Tab 한 번에 라디오 묶음 하나로 들어가고, 화살표로 바뀌며, 알림 "하루 2시간으로 바꿨어요"가 `aria-live=polite` 로 한 번. 초점은 고른 칸에 그대로.
- 초점 고리는 2px 강조색 (흰 바탕에서 약 4:1, 기준 3:1 넘음). 처음 고르기 단추 셋도 44px, 같은 고리.
- ④ 막대에 `role=img` 와 이름 "84시간 중 51시간. 공부할 거리 17개, 그중 4개는 맞는 자료가 없어요". ⑤ 주 칸마다 "4주차 14시간 27분, 한 주 14시간을 27분 넘어요 …".
- 회색 정리 뒤 패널·대화 글은 모두 먹색 13px 이상. 남은 옅은 글은 단계 길의 안 그린 쪽(예외)뿐.
- 눈금 글은 세 안 같은 자리, 고른 눈금만 굵게. 목표선이 84→168→252 로 옮겨 가 "같은 자, 다른 길이"가 잘 읽힌다.

## 반드시 (발표 전에)
1. **빗금 하나가 두 뜻이다.** ④ 막대의 빗금은 "따라 해 볼 자료"(`.seg-practice`), ⑤ 막대의 빗금은 "넘친 시간"(`.over-mark`). 게다가 ④ 범례에는 빗금 칸이 없다 (범례는 ■ 자료로 공부할 것, □ 맞는 자료가 없는 것 둘뿐).
   - 사진: `30-budget-252-materials-1440.png` (빗금 조각이 절반쯤인데 설명 없음), `31-budget-252-weeks-1440.png` (같은 빗금이 "넘친 시간").
   - 고침: ④ 의 실습 몫은 빗금 대신 다른 무늬(예: 조각 위쪽 절반만 먹 100% 로 채우기, 또는 점무늬)로 바꾸고, ④ 범례 묶음 줄에 그 무늬 칸 하나와 "따라 해 볼 자료 몫"을 252 에서만 더한다. 빗금은 ⑤ "넘친 시간" 하나에만 쓴다 (`color-not-only` 와 "한 무늬 한 뜻").

## 고침 (이번 주 안에)
2. **막힌 상태가 눈에 안 보인다.** 자료를 찾는 동안 `aria-disabled` 와 `cursor: progress` 만 걸리고 칸 모양은 그대로다. 화살표를 누르면 값이 바뀌었다가 소리 없이 되돌아간다.
   - 고침: `.budget[data-locked] .budget-opt span { opacity: .45 }` (가이드 `disabled-states` 0.38~0.5). 되돌릴 때 알림 한 번 "자료를 다 찾은 뒤 바꿀 수 있어요".
3. **눈금에 눈금 표시가 없다.** "84시간·168시간·252시간" 글만 있고 막대 위 자리를 짚는 선이 없다. 안 고른 두 자리는 글 가운데를 눈으로 막대에 맞춰야 한다.
   - 사진: `30-budget-84-materials-1440.png`, `33-budget-roundtrip-390.png`.
   - 고침: `.tick::before` 로 막대 바로 아래 1px × 6px 먹 선. 252 자리는 목표선이 틀 끝과 겹쳐 테두리처럼 보이니 (`30-budget-252-materials-1440.png`) 목표선을 틀 위아래로 4px 더 길게 낸다(지금 `.meter` 안쪽 여백만큼만 나옴 → 8px).
4. **390 에서 ④ 조각이 바코드다.** 3시간 조각이 약 4px, 사이 틈이 1~2px 라 조각 수를 셀 수 없다.
   - 사진: `33-budget-roundtrip-390.png`, `30-budget-84-materials-390.png`(과정 칸).
   - 고침: 쪽 너비 600px 아래에서는 조각 사이 틈을 없애고 묶음(자료 있음 / 자료 없음 / 실습 몫)마다 한 덩어리로 칠한다. 개수는 범례 줄이 이미 말한다.

## 손볼 것
5. **고른 칸과 안 고른 칸의 차이가 얇다.** 1px 먹 테두리 + 먹 8% 바탕 + 600 굵기. 화면에서는 보이지만 발표 화면(빔)에서 흐려질 수 있다. 안 고른 칸 테두리(`--line-strong`, 흰 바탕과 약 1.6:1)도 칸 경계로는 옅다.
   - 사진: `31-budget-84-weeks-1440.png`. 고침: 고른 칸만 `inset 0 0 0 2px var(--ink)`. 강조색은 쓰지 않는다 (S5 그대로).
6. **1440 에서 고르기 칸이 너무 넓다.** 세 칸이 머리 전체(약 600px)를 채워 쪽 머리가 그림보다 무거워 보인다.
   - 사진: `30-budget-168-materials-1440.png`. 고침: `.budget { max-width: 360px }` (칸당 약 112px, 44px 높이 그대로). 1024·390 은 지금 그대로.
7. **안을 바꾸면 3단계 표의 열이 바뀐다.** 84 표에는 "시간" 열이 없고 168·252 에는 있다. 바꿀 때 표 폭이 흔들린다.
   - 사진: `30-budget-84-materials-1440.png` ↔ `30-budget-168-materials-1440.png`. 고침: 84 에도 "3시간" 열을 둔다 (값은 저장본).
8. **④ 묶음 제목이 안마다 다르다.** 84 는 "따로 공부할 것 17개", 168·252 는 "공부할 거리 28개". 같은 쪽 같은 자리의 이름이 바뀌면 바꾸기 전후를 견주기 어렵다.
   - 고침: 세 안 모두 "공부할 거리 28개"로 두고, 84 의 "하면서 배울 것 11개"는 지금처럼 아래 줄로.
9. **⑤ 84 그림 위쪽이 비어 보인다.** 세 안이 같은 자(가장 긴 주)라서 84 막대가 아래 절반에만 있다 (`31-budget-84-weeks-1440.png`). 같은 자는 설계대로 맞으니 고치지 않되, 한도 점선 이름표 "한 주 14시간까지"를 선 바로 오른쪽 위에 붙여 빈 위쪽과 떨어져 보이지 않게만 한다.
10. **표의 "–" 가 옅다.** `.pri-none` 이 `--faint` 에 투명도 0.6 (흰 바탕에서 약 2:1). "프로젝트 일 없음"이라는 뜻이 있는 칸이니 투명도를 빼고 `--faint` 그대로 (4.9:1).
   - 사진: `31-budget-252-weeks-1440.png` 표의 1·2주차.
11. ⑤ 넘침 "+N시간" 글이 1440 에서는 막대 위, 1024 에서는 그림 아래 한 줄로 간다 (`31-budget-252-weeks-1024.png`). 둘 다 읽히지만 1024 줄 "넘친 주: …"가 굵은 글이라 큰 숫자처럼 보인다. 500 굵기로.

## 판정
고르기 칸의 키보드·aria·44px·대비는 통과, 다만 ④ 빗금이 ⑤ 와 뜻이 겹치고 범례에 없어(1번) 그 하나를 고치기 전에는 발표에 내지 않는 것이 맞다 — 1번 고친 뒤 통과.
