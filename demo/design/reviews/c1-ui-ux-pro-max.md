# c1 검토 · ui-ux-pro-max 렌즈 (시험 주 넣기 + 정리 리포트 새 모양)

본 것: `DESIGN_RULES.md`, `design/exam_brief.md`, `design/reviews/v6-report-spec.md`, `README.md`, 사진 23·24·25·31·32·36·18-reduced-report.
직접 돌려 본 것: 새 서버 8793 (`--speed 0`), 머리 없는 Chrome 1440×900·390×844. 리포트 줄 키보드, `공고에서 보기` → `리포트로 돌아가기` 오가기, 노랑 위 초점 고리, 붙는 머리, 손가락 단추 크기, 시험 이름표 위치를 쟀다. 끝나고 서버를 껐다 (8770 은 건드리지 않음).

## 잘 된 것 (그대로 둔다)
- 리포트 줄 Tab 차례 = 읽는 차례. Enter 로 펼치면 한 줄만 열림. 펼친 몸통 안 링크 → `공고에서 보기` → 다음 줄로 자연스럽게 이어진다.
- 초점 고리: summary 와 ① 형광펜 모두 2px 주황, 2px 띄움. 노랑 밖 흰 바탕에 그려져 잘 보인다. 두 줄로 꺾인 15번 형광펜도 고리가 끊기지 않고 보인다 (옆 줄은 옅은 노랑이라 대비 충분).
- 붙는 머리: 펼친 줄을 내려 읽어도 summary 가 칸 위에 붙는다. Shift+Tab 으로 몸통 링크에 돌아가도 링크가 머리 밑에 가려지지 않았다 (1440·390 둘 다, `scroll-padding-top` 48px 덕).
- 오가기: `공고에서 보기` → ① 형광펜 6 고름·화면 안·초점(`:focus-visible` 참), 알림 "공고의 6번 문장이에요". `리포트로 돌아가기` → 6번 줄 펼침·초점. 390 에서 이 단추 44px.
- 390 손가락 단추: `공고에서 보기` 44, summary 60~92, 리포트 복사·받기 44. 넘침 없음.

## 반드시 (발표 전에 고친다)
1. **390 12주 그림에서 "중간고사9주" 가 붙어 한 낱말로 읽힌다** (U5). 잰 값: 중간고사 글 오른쪽 끝 196px, "9주" 왼쪽 끝 197px, 틈 1px. 이름표 상자 41px 에 글 45px 이라 상자 밖으로 4px 넘친다. 사진 `31-*-weeks-390`, `24-weeks-pair-390` 에도 그대로 있다.
   고칠 것: `panel.css` 의 600px 아래 주 이름을 1·4·9·12 → **1·4·11·14** 로 (시험 칸 바로 옆 주 이름을 숨긴다). 기말고사 오른쪽 맞춤처럼 중간고사도 가운데에서 넘치지 않게 둔다. `shots.py` 에 "보이는 주 이름·시험 이름표 글 상자끼리 4px 이상 떨어짐" 검사를 더한다 (상자가 아니라 `Range` 로 잰 글 너비로).
2. **리포트 쪽 상태 줄이 "사람이 미리 만들어 둔 결과예요" 를 잃는다.** 줄에 초점만 옮겨도 "공고의 8번 문장" 으로 바뀌고, 돌아온 뒤에도 "공고의 6번 문장" 이 남는다 (사진 18-reduced-report, 36 에도 보임). 2절 "다시 틀기임을 숨기지 않는다" 를 어기고, 배지 번호를 한 번 더 말할 뿐이다 (S9).
   고칠 것: `panel.js` 의 `line()` 은 주석대로 짝을 그리는 쪽에서만 hint 를 쓴다. `const line = (now) => (hinted != null && now !== 'search' && now !== 'report' ? hinted : statusOf[now]);`. 번호는 알림(`announce`)으로만. `shots.py` 의 `check_back` 에 상태 줄 == "사람이 미리 만들어 둔 결과예요" 를 더한다.

## 고침 (이번 회차에)
3. **시험 주가 키보드·화면 읽기에서 사라진다.** 주 막대는 `button` 열두 개(aria-label "6주차 …", "9주차 …")인데 시험 칸은 그냥 글이라, Tab 으로 막대를 돌면 6주차 → 9주차로 건너뛴다. 왜 비었는지 듣지 못한다.
   고칠 것: 시험 이름표에 `role="img"` + `aria-label="7~8주차 중간고사, 공부·프로젝트 없음"` (기말도 같은 꼴). 막대 묶음(`.bars`)에 `role="group"` `aria-label="학기 16주 계획"` 을 단다.
4. **시험 이름표가 600 굵기라 "고른 주" 표시와 겹친다.** 지금 주 이름을 고르면(`data-lit`) 그 이름도 600 이 된다. 굵게 = 고름이라는 뜻이 흐려진다.
   고칠 것: `.exam-name` 은 500, 고른 주 이름만 600. 막대가 없는 것은 글로 이미 말한다 (색·굵기에 기대지 않음).
5. **390 에서 공부 시간 고르기 단추가 36px** (2절 "손가락 단추 44px"). 리포트·12주 쪽 맨 위에 늘 있는 단추라 이번 변경에서 가장 자주 누른다.
   고칠 것: `@media (max-width: 1023.98px) { .budget-opt { min-height: var(--control); } }`.

## 손볼 것 (시간이 남으면)
6. 390 단계 길 숫자 단추 18×18, 1440 높이 20px. `6 리포트` 로 돌아가는 두 번째 길이라 이번에 더 쓰인다. 눈에 보이는 크기는 두고 `::before` 로 누르는 칸만 44px 로 넓힌다 (옆 칸과 겹치지 않게 `li` 간격 확인).
7. 1440 `리포트로 돌아가기` 높이 28px. 같은 쪽의 `공고에서 보기`·복사 단추는 36px. 36px 로 맞춘다.
8. 키보드로 돌아가기: 형광펜에 초점이 있을 때 `리포트로 돌아가기` 까지 Shift+Tab 7번. 형광펜에서 Esc 는 지금 아무 일도 안 한다 (짝 풀기만). store.back 이 있을 때 형광펜에서 Esc 두 번째 = 리포트로 돌아가기, 또는 알림 끝에 "리포트로 돌아가려면 Esc" 를 붙인다 (화면 글은 늘리지 않음).
9. 390 펼친 줄의 붙는 머리가 92px (두 줄 형광펜 + `실제 질문` 줄) 로 보이는 칸 608px 의 15%. 붙어 있을 때만 `실제 질문` 표시를 숨기면 60px 로 준다 (`.report-row[open] > summary .q-mark` 를 붙은 상태에서 숨김. 펼친 몸통 이름표가 "실제 면접 질문" 을 이미 말한다).
10. 한도 점선 "한 주 14시간까지" 가 시험 칸 위로도 지나간다. 시험 칸은 시간이 0 이라 문제는 없지만, 점선을 시험 칸에서 끊으면 "이 주는 쉼" 이 더 또렷하다. 그림 하나 원칙(S1)을 깨지 않는 선에서만.

## 판정
조건부 통과: 1(390 이름표 붙음)과 2(다시 틀기 알림 사라짐)를 고치고 `shots.py` 에 두 검사를 더하면 통과. 리포트 줄의 키보드·초점·붙는 머리·오가기는 잘 됐다.
