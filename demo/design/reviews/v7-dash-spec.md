# 데모 숫자·차트 설계서 (대시보드 참고, 리드가 다섯 설계안을 합침, 2026-11-18)

근거: `design/dash_brief.md`, `design/proposals/dash-{frontend-design,taste-skill,ui-ux-pro-max,toss-writing,frontend-ui-engineering}.md`. `DESIGN_RULES.md` 1절(U4-1 포함)이 위. 시험 기간·리포트 고침(`c1-lead.md`)이 끝난 코드 위에 만든다.

## 0. 정한 것
- **가져옴**: 카드 짜임(머리 한 줄 + 그림 하나 + 범례), 숫자와 단위의 굵기 나눔, 얇은 범례 표, 고른 간격(16/24), 둥글기 12 + 1px 선.
- **안 가져옴** (다섯 모두): 그림자 카드, 아이콘 동그라미, 회색 설명 줄, 증감 % 배지, 장식 선 그래프, 도넛, 색 여러 개, 점선 격자·회색 축, 기간 고르기 단추, 값 상자(tooltip). 차트 라이브러리(ApexCharts 등)도 안 씀: 크고(500KB), 자체 움직임, 짝 연결·shots 선택자를 깸. 손으로 그린 HTML 막대 그대로.

## 1. 부품 (`static/js/cards.js`, 80줄 안, fe-eng)
- `statHead(number, unit, line)`: 답 맨 위. 숫자 20px 600 `tabular-nums` + 단위 15px 400 먹, 숫자와 단위는 한 줄에서 안 떨어짐(`white-space: nowrap`). 아래 한 줄은 지금 그대로. 상자 없음. 지금 `chat.headline` 호출 자리를 그대로 씀.
- `chartCard(title, body, aside)`: 패널 ②~⑤ 의 주 그림 하나만 감싼다. 머리 줄 = 왼쪽 사실 문장 14px 먹 + 오른쪽 공부 시간 고르기(있는 쪽만). 1px `--line`, 둥글기 12, 그림자 없음, 안쪽 16/24. 쪽마다 하나, 겹치지 않음. 390 에서 고르기는 머리 아래 줄.
- `legend(rows)`: ②·④·⑤ 의 따로 놀던 범례를 하나로. 줄마다 10px 견본 + 이름 13px 먹 + 개수 오른쪽 맞춤 13px 600 tabular, 줄 높이 32. 견본 수 = 그림에 실제로 칠한 종류 수.
- 움직임은 지금 규칙 (사건마다 하나, transform·opacity). 중복된 "움직임 줄이기·숨김이면 건너뜀" 검사는 `icons.js` 의 `play()` 하나로.

## 2. 쪽별
- ① 패널 머리 "29문장 중 핵심 19 · 역량 29" → "핵심 문장 29개 중 19개 · 역량 29개" (toss).
- ② 깔때기: 아직 안 한 단계의 숫자를 회색으로 미리 보이던 것 → 그 단계가 시작될 때까지 숫자 칸을 비워 둠(폭은 유지). 이름표·› 는 먹. 마지막 "1위" → "1개" + 이름표 "필수를 다 다룬 후보". ✓ 표시 뺌. 후보 점: 논문·저장소를 짙기(먹 30%, 1.84:1 로 S4 위반)로 가르지 않고 둘 다 먹 60% + 덩어리 사이 8px 와 이름표로 가름. 순위 표는 1위 줄만 굵게. 390: 후보 칸 10×10 (한 칸 28px 이상), DB 숫자 20px.
- ③ 덮기 띠 아래 설명 두 줄 → 범례 한 줄 (`legend`).
- ④ 공부 시간 막대: 머리 줄 = 사실 문장("84시간 중 51시간을 자료로 채웠어요") + 고르기. 84·168·252 눈금은 둔다 (세 안 견주기, v5 결정). 범례 개수 오른쪽 맞춤.
- ⑤ 12주 막대: 머리 줄 = 사실 문장("일하는 12주 중 10주는 한 주 14시간 안이에요") + 고르기. 막대 위에 그 주 합계(13px 먹, tabular), 위 빈 높이 96px 이하, 맨 위 조각만 위 모서리 2px 둥글게. 격자 없음.
  - 답 큰 숫자 "프로젝트 일 300시간" 은 팀 합이다 → "팀 프로젝트 일 300시간" (toss 지적, 한 사람 기준 한 줄과 헷갈림).
- ⑥ 머리 글 13 → 14px.
- 강조색은 쪽마다 한 곳: 끝난 ② 는 1위 칸 고리만, ④·⑤ 는 진행 중(`[data-now]`)에만.

## 4. 검사
- pytest: 새 서버 값 셋(db.total, inside, 주별 합)이 세 공부 시간 안에서 저장본과 같음.
- shots.py (세 너비, 세 공부 시간):
  - 숫자 칸 `tabular-nums`, 숫자·단위 한 줄, 숫자 칸 오른쪽 끝 맞춤 1px 안.
  - `.chart-card` 쪽마다 하나 이하, 겹침 없음, 상자 세 겹 없음, 둥글기 두 가지(12/6)만.
  - 범례 견본 수 = 칠한 종류 수, 범례 개수 = 저장본.
  - 표시 대비 3:1 이상 (저장소 점 포함), 강조색 쪽마다 한 곳.
  - 깔때기: 단계가 시작되기 전 숫자 칸 비어 있음.
  - 아이콘 동그라미 0, 도넛·선 그래프 0, 그림자 0.
  - ⑤ 막대 위 합계 = 서버 값, 위 빈 높이 ≤ 96px.
  - 답 하나가 1440×900 대화 칸 한 화면 안, 390 넘침 없음, U4-1 검사 그대로.
