## 고침
1. **HALUNA 가 한국어 문장의 문장부호까지 그린다.** `unicode-range: U+0020-007E` 라서 `?` `,` `.` `(` `)` 가 HALUNA 로 나온다. 빈 화면 인사 "살펴볼까요?" 의 물음표만 굵고 모양이 달라 튄다 (`01-empty-1440`). 한글 제목에 영문 글꼴 부호가 끼면 한 줄 안에서 글꼴이 둘로 보인다.
   고칠 것: `tokens.css` 의 `unicode-range` 를 `U+0030-0039, U+0041-005A, U+0061-007A` (숫자·영문)로 줄인다. "111,753" 의 쉼표는 Pretendard 로 가도 괜찮다. shots: 인사 끝 `?` 의 글꼴이 Pretendard.
2. **390 ⑤ 주 막대 단추가 17px 폭이다.** 막대 12개가 모두 `button` 인데 누르는 칸이 17×167, 옆 칸과 틈 4px. 2절 "손가락 단추 44px" 은 물론 WCAG 2.2 의 24px 도 못 넘는다. 옆 주를 잘못 누르기 쉽다.
   고칠 것: 600px 아래에서 칸 사이 틈을 단추 안쪽 여백으로 옮겨 누르는 칸을 칸 너비 전체(약 21px)로 넓힌다 (보이는 막대 폭은 그대로). 이것으로도 모자라니, 같은 내용을 주는 길(대화 칸 주별 표의 줄, 그 아래 `프로젝트 일 N개 보기` 44px)이 있음을 받아들인다.
3. **390 ④ 펼친 묶음 안 공부할 거리 줄이 32px.** 묶음 머리(`자료로 공부할 것 13개` 등)는 44px 인데 그 안 13줄 summary 는 32px. 휴대폰에서 가장 많이 누르는 목록이다.
   고칠 것: `@media (max-width: 1023.98px)` 에서 이 summary 만 `min-height: var(--control)` (44px). 접힌 묶음 안이라 화면 길이 걱정은 적다.

## 손볼 것
4. 로고 "JOB AWS" 가 HALUNA 15px 에서 A 가 "Д" 처럼 읽힌다 (1440·390 사진). 16~17px 나 자간 0.02em 를 한 번 견줘 본다. 단추 aria-label 은 "JOB AWS 새 공고" 라 화면 읽기는 괜찮다.

6. (1회차 6) 390 단계 길 숫자 단추 18×18, 1440 높이 20px. `::before` 로 누르는 칸만 넓힌다.
7. (1회차 8) 형광펜에서 리포트로 돌아가려면 Shift+Tab 여러 번. store.back 이 있을 때 형광펜에서 두 번째 Esc = 리포트로 돌아가기.
