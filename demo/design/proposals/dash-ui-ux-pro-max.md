# 숫자·차트 다듬기: ui-ux-pro-max 렌즈 + dataviz 방법

근거: `design/dash_brief.md`, `DESIGN_RULES.md`, `design/guides/ui-ux-pro-max.md` 규칙 id, 템플릿 그림(`preview/s_02.jpg`·`s_12.jpg`)과 `home*Chart.js` 설정(데이터로만 읽음), 지금 사진 `shots/12-scene-c-pick-*`, `13-project-result-1440`, `20-materials-result-1440`, `23-weeks-result-*`.
대비 수는 `tokens.css` 값을 흰 패널(#fff) 위에 겹쳐 WCAG 식으로 셈했다. 차례는 이 렌즈의 우선순위(접근성 → 누르기 → 꼴 → 배치 → 색 → 움직임).

## 0. 템플릿에서 가져올 것과 버릴 것
- 가져올 것: 차트 카드의 짜임 **제목 → 그림 → 범례**, 숫자 카드의 **이름표 위, 큰 숫자 아래**, 표시 끝의 작은 둥글림(템플릿 `borderRadius: 3~4`), 마우스를 올리면 뜨는 값 상자(`tooltip: { shared: true, intersect: false }`), 범례 점 8px.
- 버릴 것: 색 다섯 개(`colors: ["#6366f1","#22c55e","#ef4444"]` 등, S5 위반), 회색 12px 축 글(`colors: "#9ca3af"`, U4-1·대비 2.5:1), 증감 % 배지와 장식 선 그래프(지어낸 숫자·S2), 도넛(값 비교는 길이가 각도보다 정확), "This Week" 고르기(우리는 기간이 없다).

## 1. 차트별 권고
| 자리 | 꼴 | 표시 | 글·범례 | 대비(흰 바탕) |
|---|---|---|---|---|
| 답 맨 위 큰 숫자 | 숫자 하나 (차트 아님) | 20px 600 `tabular-nums` | 아래 한 줄 15px | 먹 14.4:1 |
| ② 깔때기 | **숫자 줄 그대로** | 111,753 → 1,000 → 100 → 1 | 이름표 위 13px, 숫자 아래 | 먹 |
| ② DB 점 판 | 점 단위 그림 | 점 4px | 범례 2개 (원) | 논문 60% 4.0:1 ✓ · 저장소 30% **1.84:1 ✗** |
| ② 후보 칸 100 | 칸 단위 그림, 칠 높이 = 점수 | 칸 안 먹 60% 높이, 1위 먹 + 포인트 고리 | `0점 □ ▭ ■ 5점` | 60% 4.0:1 ✓ |
| 덮기 띠 (대화·③) | 29칸 단위 그림, 3묶음 | 다 칠·반 칠·테두리 | 오른쪽 범례 3개 | 먹 ✓, 테두리 `--line-strong` 1.5:1 (빈 칸 뜻이라 허용) |
| ④ 84시간 막대 | 불릿 차트 (가로 막대 1 + 목표선) | 조각 먹 60%, 목표선 2px 먹 | "84시간 중 51시간" 위, 눈금 84·168·252 | 조각↔바탕 띠(#eee) 3.4:1 ✓ |
| ⑤ 학기 막대 | 쌓은 세로 막대 | 공부 먹 60%, 프로젝트 먹, 넘침 빗금 | 범례 3개, 한도 점선 + 글 | 공부↔프로젝트 3.6:1 ✓ |
| ⑥ 머리 숫자 | 숫자 둘 | 20px 600 | 이름표 13px | 먹 |

차트마다 한 줄씩:
- **② 깔때기는 막대로 바꾸지 않는다.** 네 값이 11만 배 차이라 같은 자로 그리면 1,000 막대가 0.9%, 1 은 0px 다. 로그 자는 발표에서 오해를 부른다. 값이 넷뿐이고 비가 극단이면 숫자 줄이 맞는 꼴이다 (dataviz "숫자가 답이면 숫자를 보인다").
- **② 저장소 점 30% 는 S4 위반.** 짙기로 가르지 말고 둘 다 먹 60% 로, 논문 덩어리 다음에 한 줄(8px) 띄워 저장소 덩어리를 두고, 덩어리 왼쪽 위에 범례를 붙인다 (자리로 가름, `color-not-only`). 같은 짙기가 두 뜻이 되지 않게 후보 칸 칠은 `--tone-*` 대신 높이로만 말한다(지금 사진은 이미 높이).
- **④ 막대**: 자료 없는 조각은 지금처럼 빈 테두리. 값 글 "84시간 중 51시간" 은 막대 왼쪽 위 그대로 (축 대신 글). 목표선이 포인트색이면 안 된다: 포인트색 ↔ 먹 60% 대비 **1.01:1** 로 조각 위에서 사라진다. 목표선은 먹.
- **⑤ 막대**: 세로축 없이 한도 점선이 자 역할을 한다. 그래서 주마다 값은 **값 상자**(3절)로 준다. 막대 위 끝 둥글림 2px(`--r-mark`), 쌓은 조각 사이 선 없음(대비 3.6:1 이라 필요 없음). 넘침 빗금은 1.5px 먹 선, 6px 간격.
- **덮기 띠**: 칸 14px, 칸 사이 3px, 묶음 사이 12px + 묶음 이름표 13px. ③ 의 표시 넷(바탕·빌림 번호·새로 더함 ＋·점선 칸)은 칸 **아래** 한 줄에만 둔다 (칸 안에 넣으면 14px 에 글이 겹친다).
- 범례 규칙(공통): 계열이 둘 이상일 때만, 그림 바로 아래 왼쪽, 13px 먹, 견본은 표시와 같은 꼴(막대는 10px 네모, 점은 8px 원, 빗금은 빗금 네모). 계열 하나(④ 목표선, 깔때기)는 범례 없이 바로 글.
- 색 규칙(공통): 값 = 먹 60% / 먹 두 단계만, 강조색은 "지금 고른 하나"(1위 고리, 켜진 주) 한 곳, 노랑은 원문 짝에만. 회색 축 글 없음.

## 2. 숫자 카드 생김새 (답 맨 위, ② 깔때기, ⑥ 머리)
- 짜임: **이름표(13px 500 먹) → 숫자(20px 600 `tabular-nums`, 단위는 붙여 13px 500)**. 템플릿처럼 이름표가 위.
- 상자는 씌우지 않는다 (S3 두 겹, 패널이 이미 한 겹). 여러 숫자는 한 줄에 24px 간격, 사이 `›`(깔때기만, 차례를 뜻함) 또는 1px `--line` 세로선(⑥, 차례 아님).
- 아이콘 동그라미: 대화 답 맨 위에만, 그 단계를 시작한 단추와 같은 그림(코드·달력·목록) 16px 를 32px `--sunk` 원에. 단추 → 답이 같은 그림으로 이어진다. 패널 안 숫자에는 없다 (U4).
- 증감 배지, 작은 선 그래프, "지난달 대비" 줄 없음 (저장본에 없는 숫자).
- 숫자 글은 소리 내 읽히게: `aria-label="DB 에 모인 프로젝트 11만 1,753개"` 처럼 이름표와 숫자를 한 문장으로.

## 3. 값 상자 (마우스·초점·누름)
- 하나의 작은 부품 `tip.js` 를 모든 그림이 같이 쓴다. 13px 먹 글, `--surface` 바탕, 1px `--line-strong`, 반경 8, 안쪽 8/12, 그림자 없음. 두 줄까지: 이름 / 값.
- 보이는 값: ② 후보 칸 "3위 · datajuicer · 필수 4점 · 우대 1점", ④ 조각 "기초 통계와 점수 흔들림 · 3시간 · Seeing Theory", ⑤ 주 "4주차 · 14시간 27분 (공부 7시간, 프로젝트 7시간 27분) · 27분 넘어요", 덮기 칸 "역량 이름 · 빌림 2".
- 마우스를 올리거나 키보드 초점이 오면 뜨고, Esc·밖으로 나가면 닫힌다. 상자 위로 마우스를 옮겨도 남는다 (WCAG 1.4.13). 표시를 가리지 않게 위쪽, 패널 가장자리면 안쪽으로 뒤집는다.
- 손가락: 누르면 지금처럼 짝 고르기(상태 줄)이고, 값 상자는 고른 동안 그대로 떠 있다. 올리기 전용 정보는 없다 (`hover-vs-tap`).
- 상태 줄과 같은 글을 되풀이하지 않는다: 짝이 있는 쪽(①③④)은 상태 줄이 이름을, 값 상자는 값만.

## 4. 접근성
- 그림마다 `<figure>` + 보이는 제목. 누를 수 없는 그림(점 판)은 `role="img"` + 요약 한 줄 (지금 `search.js` 그대로).
- 누를 수 있는 그림(후보 칸 100, ⑤ 주 16, ④ 조각)은 **탭 한 번에 들어가고 화살표로 옮기기**(roving tabindex). 100칸이 탭 100번이 되면 안 된다 (`keyboard-nav`).
- 표 보기: 그림마다 같은 값의 표가 이미 대화 칸에 있다(④ ↔ 공부할 거리 표, ⑤ ↔ 주별 계획, 덮기 ↔ 역량별 표, 후보 칸 ↔ 후보 순위). 새 "표로 보기" 단추는 만들지 않고, 그림 요약 끝에 "같은 값은 대화 칸 표에 있어요" + `aria-details` 로 그 표 id 를 잇는다.
- 값은 색만으로 말하지 않는다: 넘침 = 빗금 + 글, 일부 = 반 칠, 없음 = 테두리.
- 움직임 줄이기: 값 상자는 바로 뜨고(페이드 없음), 막대 자라기는 끝 그림만.

## 5. 좁은 화면
- **1024**: 패널 ~512px. ⑤ 그림 640 아래라 막대 위 "+N시간" 글은 숨김(지금 규칙), 대신 값 상자가 그 값을 준다. 깔때기 네 숫자 한 줄 유지.
- **390** (과정 보기): 깔때기는 한 줄로 들어간다(사진 확인) — 단 DB 숫자 32px 은 이 너비에서 20px 로 내린다(넘침 여유가 8px 뿐). 후보 칸은 20×5 → **10×10** 으로 접어 칸 ≥ 28px. 칸이 44px 가 못 되므로 칸 하나하나를 누르는 일은 두지 않고, 그림 전체를 눌러 후보 순위 표로 가게 한다 (`touch-target`).
- ⑤ 390: 눈금 글은 1·4·8·12주만(S8), "중간고사"·"기말고사"는 두 칸(약 36px)에 13px 4글자(약 52px)가 안 들어가므로 "시험" 으로 줄인다.
- 값 상자는 화면 너비 − 32px 를 넘지 않게, 넘으면 두 줄로 접는다.

## 6. 차트 라이브러리를 더할까 → **더하지 않는다, 손 SVG/HTML 유지**
- 우리 그림은 모두 맞춤형이다: 서버 사건마다 조각이 자라기, 표 줄·원문 형광펜과의 짝, 빗금, 학기 시험 칸. ApexCharts(템플릿이 쓰는 것, 약 500KB)나 Chart.js 는 이 짝과 사건 움직임을 다시 손으로 걸어야 하고, 기본값(색, 회색 12px 축, 범례 위치)을 하나하나 끄는 코드가 그림 코드보다 길어진다.
- 오프라인·판 고정 부담(파일을 `static/vendor/` 에 넣고 판 번호 고정, 라이선스 표기)도 생긴다.
- 대신 작은 공통 부품 둘만 만든다: `tip.js`(3절), `legend()`(1절 범례 규칙). 둘 다 100줄 안.
- 다시 볼 조건: 축이 있는 선 그래프나 시간 축 차트가 새로 생기면 그때 uPlot(약 45KB, 판 고정)을 검토.

## 7. shots.py 에 더할 검사
1. **표시 대비**: 그림 안 값 표시(`.seg`, `.col` 조각, `.dot`, `.cell > i`)의 칠을 읽어 바탕과 3:1 이상 (저장소 점이 지금 실패해야 한다).
2. **포인트색 한 곳**: 쪽마다 `--accent` 를 쓴 보이는 요소가 1개 이하.
3. **범례 짝**: 계열 ≥ 2 인 그림에 범례가 있고, 범례 견본 수 = 그림의 서로 다른 칠 수.
4. **값 상자**: ⑤ 4주차에 마우스 → 상자 글 = 저장본 값(`expected_weeks()`), 키보드 초점으로도 같은 글, Esc 로 닫힘, 상자가 패널 밖으로 안 나감 (1440·1024·390).
5. **탭 한 번**: 후보 칸 판에 탭 1번으로 들어가고, 오른쪽 화살표로 2위로, 탭 1번이면 판을 벗어남.
6. **390 칸 크기**: 후보 칸 ≥ 28px, 덮기 칸 ≥ 12px, ⑤ 이름표끼리 겹침 0.
7. **숫자 카드**: 이름표가 숫자 위, 숫자 `font-variant-numeric: tabular-nums`, 깔때기 DB 숫자 390 에서 넘침 0.
8. 기존 `SMALL_TEXT`(13px 아래·`--muted` 글 0개)를 값 상자가 뜬 사진에도 돌린다.
